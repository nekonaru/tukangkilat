# Project

- PROJECT_NAME: Tukang Kilat
- PROJECT_KIND: app
- PIPELINE: pr
- DESCRIPTION: Aplikasi Android native untuk memesan jasa teknisi rumah terverifikasi (listrik, pipa, servis AC) dengan pembayaran, pelacakan, dan penilaian.
- DEFAULT_LANGUAGE: id

## Notes

- Stack: Kotlin, Jetpack Compose (app), Ktor + Exposed + Flyway + PostgreSQL (backend), modul shared Kotlin JVM.
- Monorepo: `shared/`, `backend/`, `app/`, `docker-compose.yml`, `docs/`.
- Dokumen sumber: `docs/PRD.md` (spesifikasi), `docs/MASTER_PROMPT.md` (urutan fase).
- UI dalam Bahasa Indonesia; kode, tabel, dan komentar dalam Bahasa Inggris.
