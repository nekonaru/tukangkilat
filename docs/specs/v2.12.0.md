# Spec: v2.12.0 audit and feature expansion

## Goal

Fix concrete defects found in a full audit and add three user-facing capabilities without adding heavy dependencies.

## Done criteria

- A consumer can list verified technicians, filter by skill and search by name; a technician receives 403 on the consumer route.
- A consumer can add and edit addresses from Akun, including GPS capture with manual coordinate fallback.
- Notifications survive process death through a Room table created by a 3 to 4 migration that preserves favorites.
- Export and import round-trip all tables including refresh_tokens; unsafe archive entry names are rejected.
- A fresh install applies migrations V1 to V4, an existing install is adopted without re-running them, and a startup failure exposes a retry action.
- All existing and new tests pass; debug and release builds succeed; no em or en dash in changed files.

## Constraints

- Indonesian UI strings, English code and comments.
- Embedded backend stays inside the APK, no external server required.
- No new dependencies.
